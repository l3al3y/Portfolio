PROJECT 01 · ANDROID SYSTEMS & RELEASE

SMC Crows v3.0

Android 17 target compatibility, multi-tier dynamic hardware skinning, and non-destructive account preservation.

120 FPS PILOT SKINNING SDK 37 / 16 KB PAGE COMPAT S26 ULTRA VERIFIED
Problem & Constraints

Modern Android 17 runtime changes, 16 KB page-size enforcement, and Qualcomm Adreno GPU memory mapping caused fatal driver freezes and render stutter on flagship devices.

Implementation & Architecture

Built release pipeline with pageSizeCompat="0x20" and 16 KB ZIP page alignment. Engineered multi-tier dynamic skinning routing 100% GPU hardware skinning for pilots while using CPU Neon fallback for mechas.

PROJECT 02 · COMPUTER VISION & CAPSTONE

Hybrid Self-Checkout Verification

A second pair of eyes for retail checkouts. Barcode identity meets real-time visual cross-validation.

77.4% PRECISION YOLOV8 + OPENCV 50 EPOCHS BENCHMARK
Problem & Challenge

A barcode alone cannot verify whether the item scanned is the actual physical product placed in bagging. Item-switching and missed scans create significant retail shrinkage.

Solution & Results

Engineered a hybrid validation pipeline pairing YOLOv8 item recognition with USB barcode scanner serial inputs. Tested on custom Malaysian retail dataset with 77.4% precision and 72.0% recall.
