# Skill: Multi-Portal Sync (`portal sync`)

## Command Usage
```bash
python cli.py portal sync --portal all
python cli.py portal sync --portal myfuturejobs
python cli.py portal list
```

## Connectors Supported
- 🇲🇾 **MYFutureJobs** (`myfuturejobs.gov.my` - Official MY Govt Portal)
- 🇲🇾 **MauKerja** (`maukerja.my`)
- 🇲🇾 **JobStreet Malaysia** (`jobstreet.com.my`)
- 🇸🇬 **LinkedIn Southeast Asia** (`linkedin.com/jobs`)
