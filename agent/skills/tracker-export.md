# Skill: Master Excel Tracker Export (`tracker export`)

## Command Usage
```bash
python cli.py tracker export --out data/JobTracker.xlsx
```

## Dashboard Features
- Multi-sheet layout: Overview KPI Dashboard, Applied Jobs Audit, ATS Scoring Analytics, Portal Metrics.
- Auto-styled columns, conditional formatting for match scores, and status summaries.
