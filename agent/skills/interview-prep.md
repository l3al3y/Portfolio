# Skill: Interview Preparation (`interview prep`)

## Command Usage
```bash
python cli.py interview prep --title "Network Engineer" --company "TechNova"
```

## Features
- Calculates quantitative interview chance percentage (0 - 95%).
- Generates 5 high-yield technical interview questions based on CCNA / Festo AI / Capstone project metrics.
- Formulates STAR-method answer templates for candidate background.
