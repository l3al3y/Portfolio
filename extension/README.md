# IrfanLLM — Touchless AI Manga Controller (Chrome Extension)

A zero-touch, hands-free reading assistant for DemonicScans, Asura, and webtoon websites using front-camera AI posture recognition.

## 🚀 Quick Install in 3 Steps:

1. Download or extract this folder to your computer.
2. In Google Chrome, Microsoft Edge, or Brave, navigate to `chrome://extensions` in your address bar.
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** (top-left) and select this `extension` folder!

## 📖 How to Use:
1. Open any manga chapter on [DemonicScans.org](https://demonicscans.org).
2. The controller starts automatically, or click the **IrfanLLM** extension icon in your browser toolbar to toggle it!
3. Postures:
   - **Right Hand** (Chest level): Scroll Down
   - **Left Hand** (Under chin): Scroll Up
   - **No Hand**: Stop / Stationary
