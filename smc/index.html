BEFORE YOU INSTALL

A build to test.

Packaging, signatures, and local setup logic passed PC checks. Android installation, login, graphics, and matches have not been tested. This is an unofficial experimental build.

Back up your game data and account first. This APK uses a different signing certificate and cannot update the original NetEase app. Uninstalling the original can delete its data. External game resources are available in the separate 5.56 GB ZIP. This highend backup has passed file checks; compatibility with this APK still needs phone testing. It does not include a player account.

01 / ON YOUR PHONE

Download.
Install. Test.

  1. Save the APK.

    Open the download on your phone, or transfer the file from your PC by USB.

  2. Use Android’s installer.

    Open the APK in your file manager and allow installation from that app if Android asks. No Termux is needed.

  3. Restore resources, then launch.

    Download the resource ZIP and extract it on your PC. Copy its single com.netease.g93na folder into your phone’s Android/data/ folder. Read the resource restore guide for USB and PC ADB options. Restore your own Crows account backup before first launch if you have one; then check login, lobby, and a match.

If it fails, the original unmodified game and the original Crows PC kit remain the reference installation path.
