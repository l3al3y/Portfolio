How to Use on DemonicScans & Manga Websites

Because this controller is hosted directly on irfanfahmi.com/manga.js, you can use it on any mobile or desktop webtoon site with a simple 1-line bookmarklet:

javascript:(function(){const s=document.createElement('script');s.src='https://irfanfahmi.com/manga.js';document.head.appendChild(s);})();
Step 1: In Chrome, create a new bookmark named Irfan Manga.
Step 2: Paste the code above into the URL field.
Step 3: Open demonicscans.org on your phone. Tap the address bar, type Irfan, and tap the star icon. The touchless controller activates immediately!

Machine Learning & Vision Architecture

1. MediaPipe Pipeline

21 3D landmarks extracted at 30-60 FPS. Normalized relative to wrist coordinate and scaled by palm distance.

2. Random Forest Model

100 decision trees (depth 6) trained on ground-truth hand videos. Achieves 98.6% 5-fold cross-validation accuracy with zero reliance on velocity heuristics.

3. 0.3s Hysteresis Lock

Debounced scrolling cooldown prevents runaway page turns while maintaining fluid, natural reading speed.
