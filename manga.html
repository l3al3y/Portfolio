📱 How to Install on Mobile (Android & Samsung) via Kiwi or Lemur Browser

Standard mobile browsers (Chrome & Samsung Internet) strictly block all custom extensions. To use the touchless extension on mobile, use Kiwi Browser or Lemur Browser (free on Google Play, built on Chromium):

1. Install Kiwi or Lemur

Install Kiwi Browser or Lemur Browser from Google Play Store.

2. Download .zip

In that browser, visit irfanfahmi.com/manga.html and tap Download Extension (.zip).

3. Open Extensions Page

In Lemur: Type chrome://extensions in the address bar (or tap the bottom bar 🧩 icon).
In Kiwi: Tap 3 dots (⋮) → Extensions.

4. Load .zip & Read

Turn ON Developer mode → tap + (from .zip) or Load → select downloaded zip. Open DemonicScans & toggle ON!

Machine Learning & Vision Architecture

1. MediaPipe Pipeline

21 3D landmarks extracted at 30-60 FPS. Normalized relative to wrist coordinate and scaled by palm distance.

2. Random Forest Model

100 decision trees (depth 6) trained on ground-truth hand videos. Achieves 98.6% 5-fold cross-validation accuracy with zero reliance on velocity heuristics.

3. 0.3s Hysteresis Lock

Debounced scrolling cooldown prevents runaway page turns while maintaining fluid, natural reading speed.
